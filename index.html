About Smart EV Charging Planning

Welcome to the Smart EV Charging Planning System. This app helps EV users select vehicles, find nearby charging stations, book charging slots, and share feedback.

Features include: vehicle selection, range-aware station search, live routing, booking support, and customer feedback.

This GitHub Pages version is a static demo. It does not connect to the backend or save bookings and feedback.
