# EV Charging Station Preview

This repository is prepared for a static GitHub Pages preview. Login, booking, and feedback are demo-only and are not saved. The Node.js backend and local CSV data are excluded from the public repository.

After publishing this project to a public GitHub repository named `ev-charging-station`, enable **Settings → Pages → Build and deployment → GitHub Actions**. The workflow deploys the preview at:

`https://<your-github-username>.github.io/ev-charging-station/`
